# 智学引擎：个人与班级教学方案

入口：http://127.0.0.1:18090/，从首页进入教师工作台，选择“方案编排”。

## 教师操作

1. 选择本次测验，再选择班级。个人方案继续选择该班学生；班级方案点击“班级整体计划”，无需选择代表学生。
2. 核对学情摘要。个人方案使用该学生的全部有效记录；班级方案使用全班全部有效记录的加权统计、能力状态人数及证据覆盖情况。
3. 选择需要关注的知识点，填写教学目标、总时长与候选最多步数。没有本次可用题的知识点不可选；默认选两项，减少不必要生成。
4. 点击“生成方案建议”。模型结合上述学情、已审核学习知识与来源、实际题目和学习材料生成候选，再独立复核。页面展示学习行动、安排理由、时长、材料及来源。
5. 点击“采用并保存草稿”或“全部采用并保存草稿”。候选追加到下方“我的教学方案”，后台保存成功才显示已采用，不覆盖原来修改；同一候选不能重复追加，剩余候选仍可继续采用。保存失败会提示并保留原稿与候选。
6. 可以修改标题、行动、依据、时长，调整顺序或删除步骤；手工修改后须点击“保存草稿”。页面显示已保存/未保存和保存位置。切页后再次选择相同个人/班级与测验，在“我的教学方案”查看存稿；已保存内容刷新后也保留。未保存手工修改和未采用预览仅在本次页面会话保留，刷新/关闭前须保存，未保存编辑有离开提示。
7. 核对后点击“教师确认方案”。采用保存只生成草稿，不代替教师确认。个人与班级计划分别保存，班级计划不会覆盖个人计划；当前确认后才供本人或本班学生查看学习任务。

切换班级会清空旧学生与候选，再加载新班学生名单；名单按服务器分页和搜索。切换学生、测验或方案对象后，不会采用旧请求迟到返回的候选。

## 学生操作

从首页进入学生空间并选择模拟身份，在“学习任务”查看个人任务；若本班本次测验已有教师确认且仍有效的班级方案，同时出现“班级共同任务”。每组最多三步，支持打开学习内容和题目、阅读提示及提交阅读/求助/完成自评。参考答案、解析和评分点不会随学生材料接口返回。

## 分析和生成如何分工

Spring Boot根据上传记录已有评分确定性计算统计，识别证据覆盖和能力状态；模型不重新判分。方案生成由Spring整理目标范围的统计摘要，通过AI服务统一ModelProvider调用当前已配置模型，再独立复核。模型输入不含学生原答案、作答过程、评分点、参考答案或按学生逐行的班级记录。

知识来源由knowledge-service提供已审核固定学习卡。题目Q、学习材料L和教材B保持原分类。一个教学步骤可以综合使用方案所选知识点的相关材料；作答证据仍严格对应该步骤知识点。前置知识缺乏直接证据时，只能建议补充核查。

生成候选本身不修改已保存方案、学情或成绩。保存同时校验数据版本和计划版本；上传/删除改变学情后，既有个人和班级方案保留内容并标为待复核。模型失败时明确弹窗提示，保留编辑内容，不用规则结果伪装生成成功。

已有规则步骤未标时长时不凭空补值；新AI步骤有时长，总计不得超过限定时长。若追加后超过限制，需要教师调整时长或删除步骤后保存。
